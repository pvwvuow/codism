قابلیت‌های پیشرفته

Codism هم شروعِ آسان دارد (کلید بساز، درخواست بزن) و هم ابزارهای سطح پیشرفته — همه همزمان و روی یک اندپوینت.

زنجیره پشتیبان (Fallback Combos)

یک «زنجیره» فهرستی مرتب از مراحل است. وقتی مدلی به شکل combo/name درخواست شود، مراحل به‌ترتیب امتحان می‌شوند: خطای شبکه، پر شدن سقف، چالش، 429 یا خطای سرورِ یک مرحله یعنی فوراً سراغ مرحله بعدی می‌رویم. اگر همه مراحل شکست بخورند، آخرین خطا عیناً به شما برگردانده می‌شود.

مدیر پنل زنجیره‌ها را در داشبورد (تب «زنجیره‌های پشتیبان») می‌سازد و هر مرحله می‌تواند آپ‌استریم و مدل مخصوص خودش را داشته باشد — مثلاً یک کلید اصلی، یک کلید ذخیره و بعد یک ارائه‌دهنده ارزان‌تر. اگر یک «زنجیره پیش‌فرض» تعریف شده باشد، درخواست‌های معمولی هم بعد از شکست آپ‌استریم اصلی به‌صورت خودکار از آن پیروی می‌کنند؛ بدون اینکه لازم باشد چیزی در کلاینت عوض کنید.

curl https://api.tvframe.vip/v1/chat/completions \
  -H "Authorization: Bearer codism_..." \
  -H "Content-Type: application/json" \
  -d '{
    "model": "combo/my-coding-stack",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'

پیشوند مدل

برای واضح‌تر شدن منبع پاسخ، می‌توانید مدل‌ها را با پیشوند بفرستید: cc/claude-opus-5.5 دقیقاً مانند claude-opus-5.5 پردازش می‌شود (پیشوندهای cc/ و codism/ برداشته می‌شوند). ابزارهایی که نام مدل را دستکاری می‌کنند با این روش بدون مشکل کار می‌کنند.

ذخیره‌کننده توکن (Token Saver)

هر کلید می‌تواند سطح ذخیره‌کننده توکن داشته باشد (داشبورد ← کلیدهای API ← تنظیمات):

trim — فشرده‌سازی هوشمند ورودی: فاصله‌های اضافی و خطوط خالی تکراری حذف و محتوای خیلی بزرگ برش می‌خورد. مناسب خروجی ابزارها و دیف‌های طولانی.

turbo — به‌علاوه‌ی trim، یک راهنمای سیستم برای پاسخ کوتاه‌تر و بی‌حاشیه اضافه می‌شود تا توکن خروجی هم کم شود.

برای یک درخواست خاص می‌توانید آن را خاموش کنید؛ تخمین توکن‌های صرفه‌جویی‌شده در هدر پاسخ و در صفحه «مصرف» دیده می‌شود:

x-codism-token-saver: off          # bypass for this request only
# response header:
x-codism-saved-tokens: 1823

حالت دیباگ

با فعال کردن دیباگ روی یک کلید، جزئیات زنجیره (مدل، آپ‌استریم، وضعیت و تأخیر هر مرحله) در لاگ درخواست‌ها ثبت می‌شود تا عیب‌یابی «چرا پاسخ از مدل دیگری آمد؟» چند ثانیه طول بکشد. متن پیام‌های شما هرگز ذخیره نمی‌شود.

هزینه تخمینی

صفحه مصرف، هزینه تخمینی ماه را بر اساس جدول قیمت مرجع مدل‌ها نشان می‌دهد. این عدد فقط برای مقایسه و مدیریت مصرف است — قبض واقعی شما همان اشتراک پنل است.
