quickstart.py 
# pip install openai
from openai import OpenAI

client = OpenAI(
    api_key="codism_your_key",
    base_url="https://lmdevpnsviwjdycwhahh.supabase.co/functions/v1/panel/v1",  # فقط این را عوض کنید
)

stream = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Hello!"}],
    stream=True,
)

for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="")

سوال‌های پرتکرار

هزینه چطور کار می‌کند؟
هر پلن یک سهمیه توکن ماهانه دارد؛ توکن‌ها پرامپت و پاسخ را با هم می‌شمارند و هر ماه شارژ دوباره می‌شوند. تا وقتی سهمیه هست، هزینه‌ی اضافه‌ای پرداخت نمی‌کنید و مصرف‌تان در داشبورد به‌صورت لحظه‌ای نمایش داده می‌شود.
پلن‌های ارزان‌تر مدل‌ها را محدود می‌کنند؟
خیر. همه پلن‌ها به همه مدل‌ها دسترسی دارند؛ تفاوت فقط در حجم توکن و نرخ درخواست است. می‌توانید Claude Opus 5.5 یا هر مدل دیگری را در هر پلنی امتحان کنید.
با SDK رسمی OpenAI سازگار است؟
بله. کافی است Base URL و api_key را عوض کنید؛ بقیه کد دست‌نخورده می‌ماند. تمام پارامترهای استاندارد مثل stream و tools بدون تغییر کار می‌کنند.
با چه ابزارهای کدنویسی AI کار می‌کند؟
Kilo Code، Cline، Cursor، opencode، Claude Code و هر کلاینت سازگار با OpenAI. اگر ابزار شما با OpenAI صحبت می‌کند، با Codism هم کار می‌کند — فقط Base URL را تغییر دهید.
توکن چی‌ست؟
کوچک‌ترین واحد متن؛ هم ورودی شما و هم پاسخ مدل با هم شمرده می‌شوند. هر درخواست مجموع پرامپت و completion را مصرف می‌کند و در داشبورد تفکیک‌شده نمایش داده می‌شود.
استریم و فراخوانی ابزار را پشتیبانی می‌کنید؟
بله؛ SSE از اولین توکن، و Tool Calling کامل. خروجی به‌صورت Server-Sent Events استریم می‌شود و تعریف ابزارها دقیقاً مثل API اصلی OpenAI عمل می‌کند.
اگر توکن‌هایم تمام شود چه می‌شود؟
درخواست‌ها به‌جای قطع بی‌صدا، خطای واضح HTTP 402 می‌گیرند؛ شارژ مجدد یا ارتقای پلن بلافاصله همه‌چیز را برمی‌گرداند. هیچ فاکتور غافلگیرکننده‌ای صادر نمی‌شود.
پرداخت چطور است؟
برای فعال‌سازی هر پلنی با پشتیبانی در تماس باشید؛ فعال‌سازی سریع است، هر زمان می‌توانید لغو کنید و سهمیه تا پایان دوره باقی می‌ماند.
