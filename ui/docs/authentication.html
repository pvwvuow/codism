احراز هویت

کلید API خود را با هدر Authorization به‌صورت Bearer ارسال کنید.

کلیدهای API

کلیدها با پیشوند codism_ شروع می‌شوند و فقط هنگام ساخت یک‌بار نمایش داده می‌شوند. کلید را مثل رمز عبور محافظت کنید؛ اگر لو رفت، از داشبورد حذف و کلید جدید بسازید.

همه کلیدهای یک حساب، به همان سهمیه توکن حساب متصل‌اند. می‌توانید برای هر کلید محدودیت مدل تعیین کنید (مثلاً فقط gpt-4o).

ارسال کلید

curl 
curl https://lmdevpnsviwjdycwhahh.supabase.co/functions/v1/panel/v1/chat/completions \
  -H "Authorization: Bearer codism_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-4o","messages":[{"role":"user","content":"Hi"}]}'

هدر x-api-key هم پذیرفته می‌شود.

محدودیت نرخ

نرخ درخواست به‌ازای هر دقیقه بستگی به پلن دارد (بسته به پلن: از ۱۲۰ تا ۳۰۰۰ درخواست در دقیقه). وضعیت فعلی در این هدرها برمی‌گردد:

هدر معنی
X-RateLimit-Limit سقف درخواست در دقیقه
X-RateLimit-Remaining باقی‌مانده این دقیقه
X-RateLimit-Reset زمان ریست
X-RateLimit-Limit-Tokens سقف توکن در دقیقه
X-RateLimit-Remaining-Tokens توکن باقی‌مانده این دقیقه

عبور از سقف → HTTP 429 با پیام روشن.

خطاها

کد معنی
401 missing_api_key کلید ارسال نشده
401 invalid_api_key کلید نامعتبر
403 key_disabled کلید غیرفعال
403 user_disabled حساب غیرفعال
404 model_not_allowed این مدل برای کلید شما مجاز نیست
429 daily_quota_exceeded / monthly_quota_exceeded اتمام سهمیه
402 اتمام موجودی (پلن تمام‌شده)
413 body_too_large حجم بدنه بیش از ۸ مگابایت
502 upstream_error اختلال سرویس بالادست

همه خطاها JSON استاندارد OpenAI برمی‌گردند: {"error":{"message","type","code"}}
