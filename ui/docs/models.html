مدل‌ها

همه مدل‌ها از یک اندپوینت حرف می‌زنند؛ جابه‌جایی فقط عوض کردن یک رشته است.

فهرست مدل‌ها

فهرست زنده مدل‌های مجاز حساب شما از این اندپوینت می‌آید (کلید لازم است):

terminal 
curl https://api.tvframe.vip/v1/models \
  -H "Authorization: Bearer codism_your_key_here"

شکل پاسخ

response.json 
{
  "object": "list",
  "data": [
    { "id": "gpt-4o", "object": "model", "owned_by": "codism" },
    { "id": "claude-opus-5.5", "object": "model", "owned_by": "codism" }
  ]
}

هر شناسه‌ای که اینجا برمی‌گردد در پارامتر model قابل استفاده است. صفحه عمومی مدل‌ها همین فهرست را با قابلیت‌ها و توضیح فارسی نشان می‌دهد.

نگاشت خودکار

شناسه‌های gpt-4o و gpt-5 به یک مدل پیش‌فرض قدرتمند نگاشت می‌شوند؛ پاسخ همیشه شناسه واقعی بالادست را برمی‌گرداند. اگر کلید شما به مدل خاصی محدود شده باشد، فراخوانی مدل مجاز → خطای 404 model_not_allowed.
