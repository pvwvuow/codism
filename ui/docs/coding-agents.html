ابزارهای کدنویسی

راه‌اندازی Kilo Code، Cline، Cursor، opencode، Claude Code و Continue با Codism.

همه ابزارها یک تنظیمات مشترک دارند — API Provider را روی OpenAI Compatible بگذارید و دو مقدار زیر را بدهید:

تنظیمات مقدار
Base URL https://api.tvframe.vip/v1
API Key codism_…

Kilo Code

  1. در تنظیمات Kilo Code بخش API را باز کنید.
  2. Provider را روی OpenAI Compatible بگذارید.
  3. Base URL را https://api.tvframe.vip/v1 وارد کنید.
  4. API Key خود (codism_…) را وارد کنید و Model را gpt-4o بگذارید.

Cline

  1. در VSCode افزونه Cline را باز کنید و وارد تنظیمات شوید.
  2. گزینه OpenAI Compatible را انتخاب کنید.
  3. همان سه مقدار (Base URL، API Key و Model) را وارد کنید.
  4. گزینه Use custom base URL را فعال کنید.

Cursor

  1. در Cursor به Settings → Models بروید.
  2. OpenAI API Key را با کلید codism_… پر کنید.
  3. Override Base URL را روی https://api.tvframe.vip/v1 بگذارید.
  4. روی Verify بزنید تا اتصال بررسی شود.

opencode

در فایل پیکربندی provider را OpenAI-compatible تعریف کنید (npm i @openai/openai نگذارید؛ فقط config):

~/.config/opencode/config.json 
# ~/.config/opencode/config.json
{
  "provider": {
    "codism": {
      "apiKey": "codism_your_key_here",
      "baseURL": "https://api.tvframe.vip/v1"
    }
  }
}

Claude Code

از متغیرهای محیطی استفاده کنید:

terminal 
export ANTHROPIC_BASE_URL="https://api.tvframe.vip/v1"
export ANTHROPIC_AUTH_TOKEN="codism_your_key_here"
claude

مدل‌ها را می‌توانید با claude model انتخاب کنید؛ شناسه‌های در دسترس را از /v1/models ببینید.

Continue

  1. فایل config.yaml افزونه Continue را باز کنید.
  2. مدل را با provider: openai تعریف کنید.
  3. apiBase را برابر https://api.tvframe.vip/v1 بگذارید و کلید codism_… را وارد کنید.

اگر ابزارتان در فهرست نیست: هر کلاینتی که با OpenAI سازگار است با همین دو مقدار (Base URL + Key) کار می‌کند. گیر کردید؟ از داشبورد برایمان بنویسید.
