Chat Completions

مرجع کامل اندپوینت اصلی برای ساخت پاسخ.

POST /v1/chat/completions

https://lmdevpnsviwjdycwhahh.supabase.co/functions/v1/panel/v1/chat/completions

بدنه درخواست

پارامتر نوع توضیح
model string، الزامی شناسه مدل؛ gpt-4o به مدل پیش‌فرض قوی نگاشت می‌شود
messages array، الزامی آرایه پیام‌ها با role و content
stream boolean true = پاسخ به‌صورت SSE
temperature number ۰ تا ۲، پیش‌فرض ۱
max_tokens integer سقف توکن پاسخ
tools array تعریف ابزارها برای فراخوانی تابع
tool_choice string|object کنترل انتخاب ابزار

نمونه درخواست

curl 
curl https://lmdevpnsviwjdycwhahh.supabase.co/functions/v1/panel/v1/chat/completions \
  -H "Authorization: Bearer codism_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-4o","messages":[{"role":"user","content":"Hi"}],"temperature":0.7,"max_tokens":512}'

پاسخ

json 
{
  "id": "chatcmpl-…",
  "object": "chat.completion",
  "model": "claude-opus-5.5",
  "choices": [
    {
      "index": 0,
      "message": { "role": "assistant", "content": "Hello! How can I help?" },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 9,
    "total_tokens": 21
  }
}

توجه: فیلد model در پاسخ، شناسه واقعی مدل بالادست را نشان می‌دهد (مثلاً نگاشت gpt-4o → claude-opus-5.5).

نکته درباره نگاشت مدل

شناسه‌های gpt-4o و gpt-5 به یک مدل پیش‌فرض قدرتمند نگاشت می‌شوند؛ بقیه شناسه‌ها عیناً به مدل هم‌نام می‌روند. برای دیدن همه شناسه‌های معتبر، GET /v1/models را صدا بزنید.
