شروع سریع

Codism یک API سازگار با OpenAI ارائه می‌دهد. اگر ابزار شما با OpenAI صحبت می‌کند، فقط دو چیز را عوض می‌کنید: Base URL و کلید API.

Base URL شما

https://lmdevpnsviwjdycwhahh.supabase.co/functions/v1/panel/v1

۱. ساخت کلید API

وارد داشبورد شوید ← تب کلیدهای API ← ساخت کلید. کلید فقط یک‌بار نمایش داده می‌شود — با codism_ شروع می‌شود و ۴۸ کاراکتر دارد.

۲. اولین درخواست

curl 
# cURL
curl https://lmdevpnsviwjdycwhahh.supabase.co/functions/v1/panel/v1/chat/completions \
  -H "Authorization: Bearer codism_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'

۳. استفاده از SDK رسمی OpenAI

SDK را به Base URL ما نشانه بگیرید؛ بقیه‌ی کد بدون تغییر کار می‌کند.

quickstart.py 
from openai import OpenAI

client = OpenAI(
  api_key="codism_your_key_here",
  base_url="https://lmdevpnsviwjdycwhahh.supabase.co/functions/v1/panel/v1",
)

response = client.chat.completions.create(
  model="gpt-4o",
  messages=[{"role": "user", "content": "Hello!"}],
)
print(response.choices[0].message.content)
quickstart.js 
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "codism_your_key_here",
  baseURL: "https://lmdevpnsviwjdycwhahh.supabase.co/functions/v1/panel/v1",
});

const response = await client.chat.completions.create({
  model: "gpt-4o",
  messages: [{ role: "user", content: "Hello!" }],
});
console.log(response.choices[0].message.content);

۴. اتصال یک ابزار کدنویسی

بیشتر ابزارهای کدنویسی یک تنظیمات OpenAI سفارشی دارند. این مقادیر را بدهید:

تنظیمات مقدار
API Provider OpenAI Compatible
Base URL https://lmdevpnsviwjdycwhahh.supabase.co/functions/v1/panel/v1
API Key codism_…
مدل هر model id از صفحه مدل‌ها

با Kilo Code، Cline، Cursor، opencode و Continue تست شده است.

اندپوینت‌های موجود

GET /v1/models فهرست مدل‌ها
POST /v1/chat/completions ساخت پاسخ چت

Embeddings و سایر اندپوینت‌های OpenAI در حال حاضر ارائه نمی‌شوند.
