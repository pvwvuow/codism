استریم

با stream=true توکن‌ها را همان لحظه که تولید می‌شوند دریافت کنید.

چطور کار می‌کند

کافی است stream: true بفرستید. پاسخ به‌صورت Server-Sent Events برمی‌گردد؛ هر رویداد یک تکه پاسخ (delta) است و رویداد data: [DONE] پایان جریان را اعلام می‌کند. دروازه Codism جریان را بدون بافر اضافه عبور می‌دهد.

نمونه

curl 
curl https://lmdevpnsviwjdycwhahh.supabase.co/functions/v1/panel/v1/chat/completions \
  -H "Authorization: Bearer codism_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-4o","stream":true,"messages":[{"role":"user","content":"Hello!"}]}'

شکل جریان

sse 
data: {"id":"chatcmpl-…","choices":[{"delta":{"content":"Hel"}}]}

data: {"id":"chatcmpl-…","choices":[{"delta":{"content":"lo!"}}]}

data: [DONE]

نکات

  • کد کلاینت OpenAI خودش استریم را مدیریت می‌کند؛ فقط stream=True بدهید.
  • اگر اتصال وسط جریان قطع شود، توکن‌های مصرف‌شده تا همان لحظه محاسبه می‌شوند.
  • هر رویداد خطا هم JSON استاندارد است؛ در SSE ممکن است میان جریان هم خطا بیاید.
